# Simulador do ThePeapleCore

Consumidor de teste do contrato e dos eventos. Não é o Core real.

- **v1 (v0.0.4):** consome o contrato de leitura e exibe os dados.
- **v0.0.6:** recebe webhooks e registra os eventos de forma legível, sem duplicar.
- **v2 (v0.1.9):** reproduz os quatro sinais com dados de exemplo e resolve tokens de estilo e datas cruas.

Regra: o simulador acessa o CMS apenas pelo contrato.
