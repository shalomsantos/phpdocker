# The peaple (CMS)

Uma pasta por micro-sistema, com interface pública explícita. Nomes sugeridos, na ordem do roadmap:

identidade-acesso, modelagem-conteudo, gestao-conteudo, contrato-leitura, fluxo-editorial,
eventos-publicacao, biblioteca-midia, auditoria, painel-admin, secoes, componentes, templates,
evolucao-componentes, home, autor-rotas, colecoes, curadoria.

Regras:

- Um módulo só depende de módulos de versões anteriores.
- Organização interna e convenções: ver `docs/05-stack.md` (após o ADR 0001).
