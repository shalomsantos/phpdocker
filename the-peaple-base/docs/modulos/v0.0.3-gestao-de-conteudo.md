# v0.0.3: Gestão de Conteúdo

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.2

## Objetivo

Criar e editar entradas.

## Entrega

- CRUD de entradas de qualquer tipo definido na modelagem
- Editor rico com saída em blocos estruturados; cada bloco carrega tipo, versão e props
- Título, resumo, slug (único e validado) e campos de SEO guardados como dado (título SEO, descrição, imagem social, noindex, canonical opcional)
- **Preview de SEO**: resultado de busca e cartão de compartilhamento calculados a partir dos campos, com avisos de tamanho; é auxílio de edição, e a saída final continua no Core
- Taxonomias básicas (categorias e tags) com associação às entradas
- Validação dos campos contra o schema

## Sinal ao Core

A entrada completa em formato estruturado, com os campos de SEO como dado.

## Pronto quando (critério de aceite)

Uma matéria com blocos é criada, editada e excluída, um slug duplicado é rejeitado e o preview de SEO acompanha a edição dos campos.

Cada critério vira teste de aceite em `tests/`.
