# v0.0.9: Painel Admin (fechamento da Etapa 1)

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.1 a v0.0.8

## Objetivo

Reunir tudo em uma interface de trabalho.

## Entrega

- Shell de navegação com menu por tipo de conteúdo
- Listagens com busca, filtros e paginação
- Ações em massa (publicar, mover de categoria, excluir)
- Telas de edição integradas à gestão de conteúdo e ao fluxo editorial

## Sinal ao Core

Nenhum. É interface sobre os outros módulos.

## Pronto quando (critério de aceite)

Um editor completa o ciclo (criar, revisar, publicar e ver o dado chegar ao simulador) apenas pelo painel.

Cada critério vira teste de aceite em `tests/`.
