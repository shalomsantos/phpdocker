# v0.0.7: Biblioteca de Mídia

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.3

## Objetivo

Gerir imagens e arquivos.

## Entrega

- Upload com validação de tipo e tamanho
- Armazenamento (disco local ou armazenamento de objetos) atrás de uma interface única
- Variações geradas (thumbnail, médio e grande, em formatos modernos de imagem)
- Metadados: alt, legenda, créditos
- Associação de mídia às entradas

## Sinal ao Core

Lista de variações com URLs e metadados, para o Core escolher qual usar em cada contexto.

## Pronto quando (critério de aceite)

Uma imagem enviada gera variações e aparece no contrato de leitura com alt e créditos.

Cada critério vira teste de aceite em `tests/`.
