# v0.0.4: Contrato de Leitura e Simulador do Core

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.3

## Objetivo

Abrir a fronteira entre The peaple e Core.

## Entrega

- API somente leitura: listar e buscar entradas publicadas por tipo, taxonomia, relação e data
- Paginação e ordenação estáveis; respostas conforme o schema versionado
- Autenticação por token de serviço
- Simulador do Core v1: consome o contrato e exibe os dados

## Sinal ao Core

É a própria fronteira. O Core nunca lê o armazenamento do CMS diretamente.

## Pronto quando (critério de aceite)

O simulador lista matérias e abre uma entrada sem acessar o banco.

Cada critério vira teste de aceite em `tests/`.
