# v0.0.6: Eventos de Publicação

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.5

## Objetivo

Avisar o Core quando algo muda.

## Entrega

- Eventos: publicado, atualizado, despublicado, excluído, agendado
- Padrão outbox: o evento é gravado na mesma transação da mudança e despachado depois
- Entrega por webhook com nova tentativa em caso de falha
- Payload mínimo: id do evento, tipo do evento, tipo e id da entrada, versão

## Sinal ao Core

O evento. O Core decide o que invalidar, reindexar ou reconstruir.

## Pronto quando (critério de aceite)

Publicar uma matéria faz o simulador registrar o evento, mesmo após falha simulada de rede, sem duplicar.

Cada critério vira teste de aceite em `tests/`.

- Apresentação: renderização, layout, formatação, SEO final e cache pertencem ao ThePeapleCore.
