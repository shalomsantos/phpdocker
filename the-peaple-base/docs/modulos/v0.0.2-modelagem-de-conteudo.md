# v0.0.2: Modelagem de Conteúdo

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.1

## Objetivo

Descrever os dados antes de criá-los.

## Entrega

- Tipos de conteúdo: matéria, página, autor e seção
- Campos tipados (texto, número, data, booleano, mídia, relação, blocos); datas e horas guardadas em formato cru (ISO 8601, UTC)
- Relações entre tipos: cada matéria pertence a uma seção canônica e a um autor
- Schema versionado; cada entrada registra a versão que usa

## Sinal ao Core

Schema publicado.

## Pronto quando (critério de aceite)

O tipo matéria existe com campos e relações com autor e seção, e alterar o schema gera nova versão sem quebrar as entradas existentes.

Cada critério vira teste de aceite em `tests/`.

- Qualquer item de versões posteriores do roadmap (ver `docs/03-roadmap.md`).
- Apresentação: renderização, layout, formatação, SEO final e cache pertencem ao ThePeapleCore.
