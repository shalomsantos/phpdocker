# v0.0.5: Fluxo Editorial

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** v0.0.3, v0.0.4

## Objetivo

Controlar o ciclo de vida do conteúdo.

## Entrega

- Estados: rascunho, revisão, agendado, publicado, arquivado
- Regras de transição por papel (autor envia para revisão, editor publica)
- Agendamento de publicação e despublicação
- Histórico de revisões por entrada, com comparação e reversão
- Token de preview e leitura de rascunho pelo contrato

## Sinal ao Core

Mudança de estado e token de preview.

## Pronto quando (critério de aceite)

Uma matéria percorre rascunho até publicado, uma matéria agendada aparece no horário e o rascunho só é legível com token.

Cada critério vira teste de aceite em `tests/`.
