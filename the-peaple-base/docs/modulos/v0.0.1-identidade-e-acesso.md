# v0.0.1: Identidade e Acesso

**Etapa:** 1 (Fundação) | **Status:** não iniciada | **Depende de:** nenhuma

## Objetivo

Definir quem entra e o que cada pessoa pode fazer.

## Entrega

- Cadastro e login com hash de senha moderno e sessão ou token
- Papéis fixos: admin, editor, autor
- Permissões por ação (criar, editar, publicar, excluir) e por tipo de conteúdo
- Verificação de permissão no servidor, exposta como função reutilizável pelos outros módulos

## Sinal ao Core

Nenhum. O Core só precisa de um token de serviço para leitura.

## Pronto quando (critério de aceite)

Um usuário de cada papel faz login e é liberado ou barrado conforme as permissões.

Cada critério vira teste de aceite em `tests/`.
