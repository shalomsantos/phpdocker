# Contrato

Fonte única do que cruza a fronteira entre The peaple e ThePeapleCore.

## O que mora aqui

- Schemas das entradas enviadas ao Core
- Leituras (API somente leitura): v1 (v0.0.4) e v2 (v0.1.8)
- Eventos e seus payloads
- Manifesto de rotas
- Definições de componentes e templates publicadas

## Regras

- Todo payload carrega a versão do schema e a versão do contrato.
- Mudou algo? Suba a versão do contrato e documente a mudança aqui.
- Versões antigas têm período de transição.
- Nenhum contrato definido ainda.
